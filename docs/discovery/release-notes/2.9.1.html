Release Notes - Discovery Search Engine - Version 2.9.1

New Features

  • [ENGINE-454] - Support for a new indexValues including match (hit) indicators

    A new top-level query field and response have been added to return tree-dimension values along with information about which values participated in the match.

Behavioral Changes

  • [ENGINE-428] - Support for match highlighting against tree type dimensions.

    The highlighting query criterion and response no longer return tree type dimension highlighting. This feature is now available in the new indexValues query response.
