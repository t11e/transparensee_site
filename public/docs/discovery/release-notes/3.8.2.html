Release Notes - Discovery Search Engine - Version 3.8.2

Behavioral Changes

  • [ENGINE-797] - /json/query is deprecated

    For consistency, engine web services are available at entry /ws/. The new entry point as of version 3.8.2 is /ws/query.

  • [ENGINE-791] - End of Support for XML-RPC

    The engine no longer supports the XML-RPC protocol.

  • [ENGINE-796] - ignoreCase HTTP query parameter is obsolete

    The engine no longer supports using the ignoreCase HTTP query parameter which was a compatibility flag for old versions of Cold Fusion.

Bug Fixes

  • [ENGINE-787] - GroupBy Index Corruption

    Fixes a problem where updating the underlying data of a groupBy dimension would cause the dimension to return inconsistent results.
