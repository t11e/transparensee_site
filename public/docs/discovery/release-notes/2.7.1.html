Improvements

  • [ENGINE-59] - Accent Folding is Available for Keyword and Tree Dimension Values

Accent folding is now available for Keyword dimensions and Tree dimensions. The dimension values now support accent folding in which accented roman characters are converted to their non-accented equivalents (é becomes e).

The default for accentFolding is "false". To enable accent folding on Keyword and Tree dimensions, set the element's accentFolding attribute to "true".
